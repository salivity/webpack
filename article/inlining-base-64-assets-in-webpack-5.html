Inlining Base64 Assets in Webpack 5

Inlining small files such as icons and images directly into JavaScript bundles as base64 data URLs significantly reduces HTTP request overhead. While Webpack 4 relied on external loaders like url-loader to handle this task, Webpack 5 eliminates the need for any external plugins or loaders by introducing native Asset Modules. This article explains how Webpack 5 natively inlines small assets as base64 URLs and how to configure size thresholds.

The Replacement for url-loader

In Webpack 5, url-loader, file-loader, and raw-loader are deprecated. You no longer need to install a third-party plugin or loader to convert files into base64 data URIs. Instead, Webpack 5 provides built-in Asset Modules categorized into four types:

  • asset/inline: Exports a data URI (base64) of the asset.
  • asset/resource: Emits a separate file and exports the URL (replaces file-loader).
  • asset/source: Exports the source code of the asset (replaces raw-loader).
  • asset: Automatically chooses between emitting a separate file and inlining as a data URI based on file size (replaces url-loader).

Configuring Automatic Inlining Based on Size

To inline small assets automatically while exporting larger files as separate assets, use the generic asset type and define a maxSize condition under parser.dataUrlCondition.

Here is a standard webpack.config.js configuration:

const path = require('path');

module.exports = {
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
  module: {
    rules: [
      {
        test: /\.(png|jpe?g|gif|svg)$/i,
        type: 'asset',
        parser: {
          dataUrlCondition: {
            maxSize: 8 * 1024, // 8 KB limit
          },
        },
      },
    ],
  },
};

In this setup:

  • Files smaller than 8 KB are inlined directly into the bundle as base64 data URLs.
  • Files equal to or larger than 8 KB are emitted as separate files in the output directory.
  • The default maxSize is 8 KB (8192 bytes) if left unspecified.

Forcing Base64 Inlining for All Matching Assets

If you want to unconditionally convert all matching files into base64 URLs regardless of file size, use type: 'asset/inline':

module.exports = {
  module: {
    rules: [
      {
        test: /\.svg$/i,
        type: 'asset/inline',
      },
    ],
  },
};

This configuration converts every imported .svg file directly into a base64-encoded string within your bundle, bypassing any size threshold checks.
