Configure Webpack Externals to Load React via CDN

Configuring Webpack externals allows you to exclude heavy libraries like React and ReactDOM from your compiled JavaScript bundle, opting instead to load them through a Content Delivery Network (CDN). This approach reduces overall bundle size, speeds up build times, and leverages browser caching across different sites using the same CDN assets. This guide explains how to define the externals property in your Webpack configuration, include the necessary CDN script tags in your HTML, and maintain standard import syntax within your application code.

1. Update the Webpack Configuration

Open your webpack.config.js file and add the externals property to the exported configuration object. The externals field maps the module name used in your import statements to the global variable exposed by the external script.

module.exports = {
  // ... other webpack settings
  externals: {
    react: 'React',
    'react-dom': 'ReactDOM'
  }
};

In this configuration:

  • react and 'react-dom' refer to the module names used in statements like import React from 'react'.
  • 'React' and 'ReactDOM' refer to the global variables that the CDN-provided scripts attach to the browser's window object.

2. Include CDN Scripts in Your HTML

Because Webpack no longer packages React into your bundle, you must include the libraries via <script> tags in your HTML file before your bundle executes.

If you are using a static index.html or managing it with HtmlWebpackPlugin, include the scripts in the <head> or at the end of the <body>:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>React App</title>
</head>
<body>
  <div id="root"></div>

  <!-- CDN scripts must load before your application bundle -->
  <script crossorigin src="https://unpkg.com/react@18/umd/react.production.min.js"></script>
  <script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.production.min.js"></script>

  <!-- Your bundled output -->
  <script src="dist/bundle.js"></script>
</body>
</html>

3. Write Code Using Standard Import Syntax

You do not need to change how you write your React code. Continue using standard ES module import statements. Webpack will automatically route these imports to the global variables specified in your configuration.

import React from 'react';
import { createRoot } from 'react-dom/client';

const App = () => <h1>Loaded from CDN</h1>;

const container = document.getElementById('root');
const root = createRoot(container);
root.render(<App />);

Key Considerations

  • Loading Order: Ensure the CDN <script> tags execute before your application bundle; otherwise, your application will fail at runtime with reference errors (e.g., React is not defined).
  • Environment Matching: Use development CDN builds during local development to preserve React's warnings and debugging tools, and switch to minified production builds for deployment.
  • Fallback Handling: If high availability is critical, implement a fallback mechanism in your HTML to load local copies of the libraries if the CDN fails to respond.
