Webpack Conditional Polyfills via User-Agent

Serving polyfills only to browsers that genuinely need them significantly reduces bundle sizes and speeds up page load times for modern users. Because Webpack is a static build tool that cannot inspect incoming HTTP requests at runtime, conditional polyfilling based on User-Agent sniffing requires a hybrid approach: Webpack generates isolated polyfill bundles at compile time, and a server or edge layer inspects the client's User-Agent header to determine whether to inject that polyfill bundle into the HTML response.

1. Generating an Isolated Polyfill Bundle in Webpack

Webpack should not bundle polyfills directly into your primary application chunk. Instead, configure a dedicated entry point for polyfills. This isolates legacy code from your core logic.

// webpack.config.js
module.exports = {
  entry: {
    main: './src/index.js',
    polyfills: './src/polyfills.js',
  },
  output: {
    filename: '[name].[contenthash].js',
    path: path.resolve(__dirname, 'dist'),
  },
  module: {
    rules: [
      {
        test: /\.js$/,
        exclude: /node_modules/,
        use: {
          loader: 'babel-loader',
          options: {
            presets: [
              [
                '@babel/preset-env',
                {
                  useBuiltIns: 'entry',
                  corejs: 3,
                  targets: 'defaults', // Configured to polyfill older targets
                },
              ],
            ],
          },
        },
      },
    ],
  },
};

In src/polyfills.js, import the required core features:

// src/polyfills.js
import 'core-js/stable';
import 'regenerator-runtime/runtime';

When Webpack builds the project, it outputs two distinct entry files: main.[hash].js and polyfills.[hash].js.

2. Identifying Browser Capabilities with User-Agent Sniffing

Because Webpack has completed its job by generating separate assets, your web server (such as Node.js/Express, Nginx, or an edge function like Cloudflare Workers) must parse the incoming request’s User-Agent header.

Using a utility like browserslist-useragent or ua-parser-js, you can evaluate whether the requesting browser meets your baseline standard for native feature support (such as ES2015+ syntax, Promises, fetch, and Custom Elements).

// server.js (Express example)
const express = require('express');
const { matchesUA } = require('browserslist-useragent');

const app = express();

// Define modern targets that do not require polyfills
const modernBrowsers = [
  'Chrome >= 80',
  'Safari >= 13.1',
  'Firefox >= 74',
  'Edge >= 80',
];

function requiresPolyfills(userAgent) {
  return !matchesUA(userAgent, {
    browsers: modernBrowsers,
    allowHigherVersions: true,
  });
}

3. Conditionally Injecting the Script Tag

When rendering the initial HTML on the server, check the result of your User-Agent evaluation. If the client is running a browser older than your modern baseline, include the polyfills.[hash].js script tag ahead of your primary application bundle.

app.get('*', (req, res) => {
  const userAgent = req.headers['user-agent'] || '';
  const needsPolyfills = requiresPolyfills(userAgent);

  const manifest = require('./dist/manifest.json'); // Maps entry names to hashed filenames

  const polyfillScript = needsPolyfills
    ? `<script src="${manifest['polyfills.js']}"></script>`
    : '';

  res.send(`
    <!DOCTYPE html>
    <html lang="en">
      <head>
        <meta charset="UTF-8">
        <title>Application</title>
      </head>
      <body>
        <div id="root"></div>
        ${polyfillScript}
        <script src="${manifest['main.js']}"></script>
      </body>
    </html>
  `);
});

Edge Caching and the Vary Header

When caching responses via a CDN or proxy, sending different HTML based on the User-Agent header requires setting the Vary: User-Agent header. However, caching on full User-Agent strings can fragment the CDN cache.

To prevent poor cache hit ratios, offload the User-Agent evaluation to an Edge Worker (e.g., Cloudflare Workers or Fastly VCL). The edge layer can normalize the User-Agent into a single binary header, such as X-Requires-Polyfills: true or false, allowing CDN nodes to cache only two versions of the document.
