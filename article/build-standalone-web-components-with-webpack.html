Build Standalone Web Components with Webpack

This article provides a practical guide on configuring Webpack to compile and bundle standard Web Components into standalone JavaScript files. You will learn how to configure the entry, output, and loaders so your custom elements encapsulate their HTML and CSS, register themselves via the Custom Elements API, and work out of the box in any browser without requiring external dependencies or stylesheets.

1. Write the Custom Element

A standalone custom element should define its template, apply its styles directly inside a Shadow Root, and register itself.

// src/user-card.js
const template = document.createElement('template');
template.innerHTML = `
  <style>
    :host {
      display: block;
      font-family: sans-serif;
      border: 1px solid #ddd;
      border-radius: 8px;
      padding: 16px;
      max-width: 300px;
    }
    h2 {
      margin: 0 0 8px;
      color: #333;
    }
  </style>
  <div>
    <h2><slot name="name">Default Name</slot></h2>
    <p><slot name="bio">No bio provided.</slot></p>
  </div>
`;

class UserCard extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    this.shadowRoot.appendChild(template.content.cloneNode(true));
  }
}

if (!customElements.get('user-card')) {
  customElements.define('user-card', UserCard);
}

export default UserCard;

2. Configure Webpack

To make the component truly standalone, all assets—including styles—must be bundled into a single JavaScript file. Do not use plugins like MiniCssExtractPlugin because they extract styles into a separate .css file. Instead, use Webpack 5's asset modules or configure css-loader to export CSS as a string.

Create or update your webpack.config.js:

const path = require('path');

module.exports = {
  mode: 'production',
  entry: './src/user-card.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'user-card.min.js',
    clean: true,
    // Allows consumers to import the file as an ES module or run it standalone
    library: {
      type: 'umd',
      name: 'UserCard',
      export: 'default',
      umdNamedDefine: true,
    },
    globalObject: 'this',
  },
  module: {
    rules: [
      {
        test: /\.js$/,
        exclude: /node_modules/,
        use: {
          loader: 'babel-loader',
          options: {
            presets: ['@babel/preset-env'],
          },
        },
      },
      {
        test: /\.css$/,
        use: [
          {
            loader: 'css-loader',
            options: {
              exportType: 'string', // Inlines CSS directly as a string for the Shadow DOM
            },
          },
        ],
      },
      {
        test: /\.html$/,
        use: 'html-loader',
      },
    ],
  },
  optimization: {
    splitChunks: false,
    runtimeChunk: false,
  },
};

3. Handle Separate CSS and HTML Files (Optional)

If you prefer to separate HTML templates and CSS files during development rather than keeping them as template literals, the configuration above allows you to import them directly:

// src/user-card.js
import styles from './user-card.css';
import html from './user-card.html';

class UserCard extends HTMLElement {
  constructor() {
    super();
    const shadow = this.attachShadow({ mode: 'open' });
    shadow.innerHTML = `<style>${styles}</style>${html}`;
  }
}

if (!customElements.get('user-card')) {
  customElements.define('user-card', UserCard);
}

export default UserCard;

4. Transpilation Considerations

Native Custom Elements require ES6 class syntax when extending HTMLElement. If Babel transpiles classes down to ES5 prototypes, the browser will throw an error when executing super() in the constructor.

To prevent issues across different environments:

  • Set your Babel target in package.json or .babelrc to modern browsers:

    {
  "targets": "> 0.5%, last 2 versions, not dead"
}

  • If you must target older runtimes, install @webcomponents/webcomponentsjs to provide the necessary Custom Elements polyfills and custom element class adapters.

5. Consume the Standalone Bundle

Run the build script:

npx webpack

The resulting dist/user-card.min.js file is fully self-contained. It can be dropped directly into any web page without a build tool:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Custom Element Demo</title>
  <script src="./dist/user-card.min.js" defer></script>
</head>
<body>
  <user-card>
    <span slot="name">Jane Doe</span>
    <span slot="bio">Frontend Developer</span>
  </user-card>
</body>
</html>
