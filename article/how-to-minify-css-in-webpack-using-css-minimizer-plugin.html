How to Minify CSS in Webpack Using CssMinimizerPlugin

This article explains how to optimize and minify CSS assets in a Webpack production build using the css-minimizer-webpack-plugin. You will learn the required packages to install, how to properly configure the plugin within webpack.config.js alongside MiniCssExtractPlugin, and how to preserve JavaScript minification while customizing CSS compression settings.

1. Install Required Dependencies

Webpack does not minify CSS out of the box; it relies on plugins to handle CSS extraction and optimization. First, install css-minimizer-webpack-plugin along with mini-css-extract-plugin and css-loader:

npm install --save-dev css-minimizer-webpack-plugin mini-css-extract-plugin css-loader

2. Configure Webpack for Production

To minify CSS, you must first extract it into separate .css files rather than injecting it into the DOM via style tags. Then, add CssMinimizerPlugin to the optimization.minimizer array in your webpack.config.js.

const MiniCssExtractPlugin = require("mini-css-extract-plugin");
const CssMinimizerPlugin = require("css-minimizer-webpack-plugin");

module.exports = {
  mode: "production",
  module: {
    rules: [
      {
        test: /\.css$/i,
        use: [MiniCssExtractPlugin.loader, "css-loader"],
      },
    ],
  },
  plugins: [
    new MiniCssExtractPlugin({
      filename: "[name].[contenthash].css",
    }),
  ],
  optimization: {
    minimizer: [
      // Extends default minimizers (such as TerserPlugin for JS)
      `...`,
      new CssMinimizerPlugin(),
    ],
  },
};

Using the syntax '...' ensures that Webpack continues to use its built-in JavaScript minifier (Terser). Omitting it will overwrite the defaults and cause JavaScript to remain unminified.

3. Advanced Configuration Options

By default, css-minimizer-webpack-plugin utilizes cssnano to remove whitespace, delete redundant rules, and shorten color codes. You can customize the optimization behavior through the minimizerOptions property:

optimization: {
  minimizer: [
    `...`,
    new CssMinimizerPlugin({
      parallel: true, // Speeds up build using multi-process parallel running
      minimizerOptions: {
        preset: [
          "default",
          {
            discardComments: { removeAll: true },
          },
        ],
      },
    }),
  ],
}

4. Verification

Run your production build command (e.g., npx webpack --mode production). Webpack will parse your stylesheets, extract them into standalone files via MiniCssExtractPlugin, and pass them through CssMinimizerPlugin to eliminate dead code, stripped comments, and unnecessary whitespace, resulting in optimal file sizes for deployment.
