React Refresh Webpack and Babel Configuration

Enabling React Refresh in a Webpack and Babel environment provides instant component updates during development without losing component state. This guide outlines the necessary packages and exact configuration settings required in both your Babel configuration and Webpack setup to implement fast refresh effectively.

1. Install Required Dependencies

To use React Refresh with Webpack and Babel, install the official runtime package alongside the Webpack plugin for fast refresh:

npm install -D -E react-refresh @pmmmwh/react-refresh-webpack-plugin

Ensure you already have the core dependencies installed: webpack, webpack-dev-server, babel-loader, @babel/core, and @babel/preset-react.

2. Configure Babel

React Refresh requires a dedicated Babel plugin to transform your React components for hot reloading. Add react-refresh/babel to your Babel configuration, ensuring it is only active in development mode.

In babel.config.js:

module.exports = (api) => {
  const isDevelopment = process.env.NODE_ENV !== 'production';

  // Cache configuration based on environment
  api.cache.using(() => process.env.NODE_ENV);

  return {
    presets: [
      '@babel/preset-env',
      ['@babel/preset-react', { runtime: 'automatic' }],
    ],
    plugins: [
      isDevelopment && 'react-refresh/babel',
    ].filter(Boolean),
  };
};

3. Configure Webpack

In your webpack.config.js, import the React Refresh Webpack plugin and add it to your configuration conditionally for development builds. You also need to enable Hot Module Replacement (HMR) in the Webpack Dev Server.

const path = require('path');
const ReactRefreshWebpackPlugin = require('@pmmmwh/react-refresh-webpack-plugin');

const isDevelopment = process.env.NODE_ENV !== 'production';

module.exports = {
  mode: isDevelopment ? 'development' : 'production',
  entry: './src/index.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.js',
  },
  module: {
    rules: [
      {
        test: /\.[jt]sx?$/,
        exclude: /node_modules/,
        use: [
          {
            loader: 'babel-loader',
            options: {
              plugins: [
                isDevelopment && require.resolve('react-refresh/babel'),
              ].filter(Boolean),
            },
          },
        ],
      },
    ],
  },
  plugins: [
    isDevelopment && new ReactRefreshWebpackPlugin(),
  ].filter(Boolean),
  devServer: {
    hot: true,
    static: './dist',
  },
};

Key Considerations

  • Development Only: Never include ReactRefreshWebpackPlugin or react-refresh/babel in production builds, as they introduce unnecessary overhead and development code into your production bundle.
  • Component Export Style: Ensure that components are exported using standard names rather than anonymous functions, as anonymous exports can break the component reconciliation tree used by React Refresh.
