How to Replace raw-loader with Webpack 5 asset/source

Webpack 5 introduced Asset Modules, providing native support for handling asset files without installing additional loader packages. One of these modules, asset/source, directly supersedes the deprecated raw-loader by injecting file contents directly into bundles as raw strings. This guide explains what the asset/source type is, why it replaces raw-loader, and how to update your build configuration to use it.

What is asset/source?

In Webpack 4 and earlier, handling non-JavaScript assets required dedicated loaders like file-loader, url-loader, and raw-loader.

asset/source is a built-in module type in Webpack 5 that reads the targeted file and exports its raw content as a JavaScript string. It is ideal for importing assets whose text content needs to be used directly in the application, such as:

  • Plain text files (.txt)
  • SVG icons or graphics imported as inline markup (.svg)
  • WebGL/OpenGL shader files (.glsl, .frag, .vert)
  • Markdown documentation (.md)

The Difference Between raw-loader and asset/source

raw-loader was an external package that had to be installed via npm and configured separately. When invoked, it parsed the requested file and exported its source as a module export.

asset/source achieves the exact same output natively. Because it is built directly into Webpack 5's core engine, it removes the need to maintain raw-loader in your package.json, reduces build complexity, and integrates more cleanly with Webpack's internal compilation lifecycle.

How to Migrate from raw-loader to asset/source

Migrating to asset/source requires updating your webpack.config.js and removing the deprecated dependency.

Step 1: Remove the Deprecated Dependency

Uninstall raw-loader from your project:

npm uninstall raw-loader

Step 2: Update webpack.config.js

Replace the loader configuration rule with the type: 'asset/source' directive.

Webpack 4 (Old Method):

module.exports = {
  module: {
    rules: [
      {
        test: /\.(txt|glsl|md)$/,
        use: 'raw-loader',
      },
    ],
  },
};

Webpack 5 (New Method):

module.exports = {
  module: {
    rules: [
      {
        test: /\.(txt|glsl|md)$/,
        type: 'asset/source',
      },
    ],
  },
};

Step 3: Importing Assets in Code

The consumption syntax inside your JavaScript or TypeScript files remains identical. The imported asset resolves directly to a string containing the file's raw contents:

import documentText from './notes.txt';

console.log(documentText); // Outputs the raw file content as a string

Summary of Benefits

Switching to asset/source eliminates unnecessary third-party dependencies, reduces node module footprint, and ensures future compatibility with modern Webpack tooling standards.
