Convert Markdown to HTML Strings with Webpack

This article explains how to configure Webpack to process Markdown files (.md) and compile them directly into rendered HTML strings for your JavaScript application. By chaining loaders such as html-loader and markdown-loader, Webpack can read Markdown content, parse it into valid HTML syntax, and export it as an importable JavaScript string.

1. Install the Required Dependencies

Webpack requires dedicated loaders to interpret Markdown and export it as a string module. The standard approach pairs markdown-loader (which relies on the marked library to parse Markdown into HTML) with html-loader (which exports the resulting HTML as a JavaScript string).

Run the following command in your project terminal:

npm install --save-dev markdown-loader html-loader marked

2. Configure Webpack

Add a new rule to the module.rules array in your webpack.config.js file to intercept .md files and pass them through the loader pipeline.

const path = require('path');

module.exports = {
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
  module: {
    rules: [
      {
        test: /\.md$/,
        use: [
          {
            loader: 'html-loader',
          },
          {
            loader: 'markdown-loader',
            options: {
              // Pass custom marked options here if needed
              pedantic: false,
              gfm: true,
            },
          },
        ],
      },
    ],
  },
};

Webpack executes loaders from right-to-left (or bottom-to-top). In this configuration:

  1. markdown-loader takes the raw Markdown file and compiles it into an HTML string using marked.
  2. html-loader processes the HTML and exports it as a standard JavaScript module string.

3. Import Markdown in JavaScript

Once configured, you can import any .md file directly into your JavaScript files like an ES module. The imported variable contains the rendered HTML string ready for injection into the DOM.

// src/index.js
import markdownContent from './content.md';

const container = document.createElement('div');
container.innerHTML = markdownContent;

document.body.appendChild(container);

Alternative: Using Remark Loader

For advanced use cases—such as parsing YAML frontmatter or adding syntax highlighting—you can replace markdown-loader with remark-loader:

npm install --save-dev remark-loader remark html-loader

In webpack.config.js:

{
  test: /\.md$/,
  use: [
    { loader: 'html-loader' },
    { loader: 'remark-loader' }
  ]
}

This alternative provides access to the extensive Remark plugin ecosystem for complex Markdown transformations before rendering to HTML.
