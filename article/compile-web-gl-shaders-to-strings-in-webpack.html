Compile WebGL Shaders to Strings in Webpack

Loading WebGL shader files as plain string constants allows developers to write modular GLSL code in dedicated .vert and .frag files while seamlessly importing them into JavaScript. This guide demonstrates how to configure Webpack to bundle GLSL shaders directly into your project's build as raw strings, covering the built-in Webpack 5 Asset Modules approach, the traditional loader method, and TypeScript type declarations.

Method 1: Webpack 5 Native Asset Modules (Recommended)

Webpack 5 includes native support for importing raw files as strings using Asset Modules, eliminating the need for external loaders like raw-loader.

1. Update webpack.config.js

Add a rule to the module.rules array matching your shader extensions (.glsl, .vs, .fs, .vert, .frag) and set the type property to 'asset/source':

const path = require('path');

module.exports = {
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
  module: {
    rules: [
      {
        test: /\.(glsl|vs|fs|vert|frag)$/,
        type: 'asset/source',
      },
    ],
  },
};

2. Import Shaders in JavaScript

You can now import shader files directly. The imported value evaluates to a string containing the raw GLSL code.

import vertexShaderSource from './shaders/vertex.vert';
import fragmentShaderSource from './shaders/fragment.frag';

function createShader(gl, type, source) {
  const shader = gl.createShader(type);
  gl.shaderSource(shader, source);
  gl.compileShader(shader);
  return shader;
}

const vertexShader = createShader(gl, gl.VERTEX_SHADER, vertexShaderSource);
const fragmentShader = createShader(gl, gl.FRAGMENT_SHADER, fragmentShaderSource);

Method 2: Handling Imports with GLSL Loaders (For #include Support)

If your shaders depend on shared chunks or modular imports using #include directives, use a specialized loader such as webpack-glsl-loader or glslify-loader.

1. Install the Loader

npm install --save-dev webpack-glsl-loader

2. Configure webpack.config.js

module.exports = {
  module: {
    rules: [
      {
        test: /\.(glsl|vs|fs|vert|frag)$/,
        use: 'webpack-glsl-loader',
      },
    ],
  },
};

This processes nested dependencies and resolves them into a single string during the build step.

TypeScript Configuration (Optional)

When using TypeScript, define ambient module declarations to prevent the compiler from throwing type errors when importing shader extensions.

Create a file named shaders.d.ts in your src directory:

declare module '*.glsl' {
  const value: string;
  export default value;
}

declare module '*.vert' {
  const value: string;
  export default value;
}

declare module '*.frag' {
  const value: string;
  export default value;
}

declare module '*.vs' {
  const value: string;
  export default value;
}

declare module '*.fs' {
  const value: string;
  export default value;
}

Ensure shaders.d.ts is covered by the include array in your tsconfig.json. TypeScript will now recognize the imported GLSL files as native string constants.
