Bundle Modern CSS in Webpack Using PostCSS

Modern CSS has evolved rapidly, introducing native features like CSS nesting and the color-mix() function directly into the browser specification. However, to ensure cross-browser compatibility and support older browsers, modern stylesheets still need transpilation. This guide explains how to configure Webpack to process and bundle these cutting-edge CSS features using PostCSS and the postcss-preset-env plugin.

1. Install Required Dependencies

To compile and bundle modern CSS in a Webpack project, you need loaders to handle CSS files and the PostCSS ecosystem to transform modern syntax. Run the following command in your terminal:

npm install --save-dev webpack webpack-cli style-loader css-loader postcss postcss-loader postcss-preset-env
  • style-loader: Injects CSS into the DOM via <style> tags.
  • css-loader: Interprets @import and url() like import/require().
  • postcss-loader: Feeds CSS through PostCSS plugins.
  • postcss-preset-env: Converts modern CSS into browser-compatible CSS based on your target browser list, including polyfills for CSS nesting and color functions.

2. Configure PostCSS

Create a postcss.config.js file in your project root. postcss-preset-env includes polyfills for CSS nesting and color-mix() (via @csstools/postcss-color-mix-function).

module.exports = {
  plugins: [
    [
      'postcss-preset-env',
      {
        stage: 2, // Includes CSS nesting by default
        features: {
          'nesting-rules': true,
          'color-mix': true,
        },
      },
    ],
  ],
};

Setting stage: 2 enables most standard draft specifications. Explicitly declaring 'nesting-rules': true and 'color-mix': true guarantees that both features are processed even if the stage configuration changes.

3. Configure Webpack

Add a rule for processing .css files inside your webpack.config.js file. The order of loaders is critical: they execute from right to left (bottom to top).

const path = require('path');

module.exports = {
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
    clean: true,
  },
  module: {
    rules: [
      {
        test: /\.css$/i,
        use: [
          'style-loader',   // 3. Injects styles into the DOM
          'css-loader',     // 2. Translates CSS into CommonJS
          'postcss-loader', // 1. Transpiles modern CSS with PostCSS
        ],
      },
    ],
  },
};

If you are using production builds where an external CSS file is preferred over injected <style> tags, substitute style-loader with MiniCssExtractPlugin.loader.

4. Write Modern CSS

Create a CSS file (src/styles.css) using native nesting and color-mix() syntax:

:root {
  --primary-color: #007bff;
  --neutral-color: #ffffff;
}

.card {
  padding: 1.5rem;
  /* color-mix creates a 20% tint of the primary color */
  background-color: color-mix(in srgb, var(--primary-color) 20%, var(--neutral-color));

  /* Native CSS Nesting */
  & .card-title {
    font-size: 1.25rem;
    color: var(--primary-color);

    &:hover {
      text-decoration: underline;
    }
  }
}

Import this stylesheet into your JavaScript entry point (src/index.js):

import './styles.css';

5. Output and Build

Run Webpack using your build command:

npx webpack --mode production

During the build process, postcss-loader intercepts the CSS. postcss-preset-env unrolls the nested .card .card-title rules into standard hierarchical selectors and provides fallback representations (such as calculated RGB/HEX values) for color-mix() when required by your target browser configuration defined in .browserslistrc or package.json. The resulting bundle maintains the developer experience of modern CSS while serving fully backward-compatible styles to the end user.
