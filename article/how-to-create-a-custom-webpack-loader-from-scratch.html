How to Create a Custom Webpack Loader from Scratch

This article provides a comprehensive guide on building a custom Webpack loader from the ground up to transform files during the bundling process. You will learn the core mechanics of how loaders interact with Webpack, how to write synchronous and asynchronous transformations, how to handle configuration options, and how to integrate your custom loader locally into a project.

Understanding a Webpack Loader

At its core, a Webpack loader is a JavaScript module that exports a standard function. Webpack executes this function when it encounters a file matching a specified rule in your configuration. The loader accepts the resource file's source content as an input, transforms it, and returns the modified source code (or passes it to the next loader in the chain).

The loader function must not be an arrow function if you need access to the loader context (this), which exposes Webpack-specific properties and utilities.

Step 1: Writing a Basic Synchronous Loader

Create a new file named reverse-loader.js. This basic loader will take text files and reverse their content:

module.exports = function (source) {
  // 'source' is the string content of the processed file
  const transformed = source.split('').reverse().join('');
  
  // Return the transformed source
  return transformed;
};

If you need to return multiple values—such as the transformed source, a source map, and metadata—use the this.callback method:

module.exports = function (source, map, meta) {
  const transformed = source.split('').reverse().join('');
  
  // Arguments: error, content, sourceMap, meta
  this.callback(null, transformed, map, meta);
  return; // Always return undefined when calling this.callback()
};

Step 2: Configuring Webpack to Use a Local Loader

To use a custom loader without publishing it to npm, configure Webpack's module rules and loader resolution settings in webpack.config.js.

Use resolveLoader to point Webpack to your local loader directory:

const path = require('path');

module.exports = {
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
  resolveLoader: {
    // Tell Webpack to look in node_modules and a local 'loaders' folder
    modules: ['node_modules', path.resolve(__dirname, 'loaders')],
  },
  module: {
    rules: [
      {
        test: /\.txt$/,
        use: [
          {
            loader: 'reverse-loader',
          },
        ],
      },
    ],
  },
};

Alternatively, you can provide an absolute path directly in the loader property:

loader: path.resolve(__dirname, 'loaders/reverse-loader.js')

Step 3: Accessing Loader Options

In Webpack 5, you can retrieve options passed via the configuration using the built-in this.getOptions() method.

Update webpack.config.js:

{
  test: /\.txt$/,
  use: [
    {
      loader: 'reverse-loader',
      options: {
        uppercase: true,
      },
    },
  ],
}

Update reverse-loader.js:

module.exports = function (source) {
  const options = this.getOptions();
  let result = source.split('').reverse().join('');

  if (options.uppercase) {
    result = result.toUpperCase();
  }

  return result;
};

Step 4: Handling Asynchronous Operations

If your transformation requires an asynchronous operation—such as fetching network data, reading another file, or running an external compilation tool—you must use this.async() to inform Webpack that the loader is non-blocking.

module.exports = function (source) {
  const callback = this.async();

  setTimeout(() => {
    try {
      const transformed = source.toUpperCase();
      // Pass null for error if successful
      callback(null, transformed);
    } catch (error) {
      callback(error);
    }
  }, 1000);
};

Step 5: Handling Raw Data (Binary Files)

By default, Webpack passes the file content as an encoded UTF-8 string. If your loader processes binary data, such as images or font files, set the raw property on the loader function to true to receive a Node.js Buffer:

module.exports = function (content) {
  // 'content' is a Buffer
  assert(Buffer.isBuffer(content));
  
  return content;
};

module.exports.raw = true;

Step 6: Testing the Custom Loader

  1. Create a sample text file in src/example.txt:

    hello world

  2. Import the file inside src/index.js:

    import content from './example.txt';
console.log(content);

  3. Run the Webpack build:

    npx webpack

  4. Check the generated bundle in dist/bundle.js. The text will appear transformed according to your loader's logic.
