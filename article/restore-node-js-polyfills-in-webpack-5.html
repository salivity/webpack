Restore Node.js Polyfills in Webpack 5

Webpack 5 removed automatic polyfills for Node.js core modules like crypto, stream, and buffer to reduce client-side bundle sizes. Consequently, projects or dependencies that rely on these built-in Node modules will encounter build errors such as Module not found: Error: Can't resolve 'crypto'. This guide demonstrates how to restore these core polyfills manually through package installations and Webpack configuration adjustments.

Step 1: Install the Required Polyfill Packages

Because Webpack 5 no longer ships with built-in shims, you must install the community-maintained browser equivalents as project dependencies:

npm install --save-dev crypto-browserify stream-browserify buffer process

Common replacements include:

  • crypto: crypto-browserify
  • stream: stream-browserify
  • buffer: buffer
  • process: process/browser
  • util: util
  • path: path-browserify

Step 2: Configure resolve.fallback in Webpack

Update your webpack.config.js file to map the native module names to the newly installed polyfill packages using the resolve.fallback property.

module.exports = {
  // ... other webpack settings
  resolve: {
    fallback: {
      crypto: require.resolve('crypto-browserify'),
      stream: require.resolve('stream-browserify'),
      buffer: require.resolve('buffer/'),
      process: require.resolve('process/browser'),
    },
  },
};

If you have a module that is imported by a dependency but never actually executed in the browser, you can disable it entirely by setting its value to false:

resolve: {
  fallback: {
    crypto: false,
    stream: false,
  },
}

Step 3: Provide Global Variables

Modules like stream and crypto often depend on global Node.js variables such as Buffer or process. To ensure these globals exist in the browser runtime, use Webpack's ProvidePlugin:

const webpack = require('webpack');

module.exports = {
  // ...
  plugins: [
    new webpack.ProvidePlugin({
      process: 'process/browser',
      Buffer: ['buffer', 'Buffer'],
    }),
  ],
};

Alternative: Automated Polyfills via Plugin

If your application relies on numerous Node.js modules, manually configuring each fallback can become tedious. You can automate the process using the node-polyfill-webpack-plugin:

  1. Install the plugin:

    npm install --save-dev node-polyfill-webpack-plugin

  2. Add it to your webpack.config.js:

    const NodePolyfillPlugin = require('node-polyfill-webpack-plugin');

module.exports = {
  // ...
  plugins: [
    new NodePolyfillPlugin(),
  ],
};

This plugin automatically configures the necessary fallbacks and plugins for almost all standard Node.js core modules.
