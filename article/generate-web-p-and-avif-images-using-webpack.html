Generate WebP and AVIF Images Using Webpack

Modern web performance requires serving next-generation image formats like WebP and AVIF without breaking backwards compatibility for browsers that only support JPEG or PNG. This article details how to automate this process in Webpack using loaders and plugins, enabling you to retain your original source images while automatically generating optimized, multi-format image variants during your production build.

Core Prerequisites

To handle on-the-fly conversion of standard image formats (JPEG and PNG) into WebP and AVIF, the recommended tool within the modern Webpack ecosystem is image-minimizer-webpack-plugin paired with the sharp library. sharp provides high-performance image transformations without requiring external binary installations.

Install the necessary dependencies via your terminal:

npm install image-minimizer-webpack-plugin sharp --save-dev

Configuring Webpack

To output multiple formats, configure Webpack using the built-in Asset Modules for basic asset emission, and leverage image-minimizer-webpack-plugin within the optimization block. The plugin's generator property allows you to produce additional formats alongside the original file.

Here is an example webpack.config.js:

const path = require("path");
const ImageMinimizerPlugin = require("image-minimizer-webpack-plugin");

module.exports = {
  mode: "production",
  entry: "./src/index.js",
  output: {
    filename: "bundle.js",
    path: path.resolve(__dirname, "dist"),
    clean: true,
  },
  module: {
    rules: [
      {
        test: /\.(jpe?g|png)$/i,
        type: "asset/resource",
        generator: {
          filename: "images/[name][ext]",
        },
      },
    ],
  },
  optimization: {
    minimizer: [
      "...",
      new ImageMinimizerPlugin({
        generator: [
          {
            // Generate AVIF images
            preset: "avif",
            implementation: ImageMinimizerPlugin.sharpGenerate,
            options: {
              encodeOptions: {
                avif: {
                  quality: 65,
                },
              },
            },
            filename: "images/[name].avif",
          },
          {
            // Generate WebP images
            preset: "webp",
            implementation: ImageMinimizerPlugin.sharpGenerate,
            options: {
              encodeOptions: {
                webp: {
                  quality: 75,
                },
              },
            },
            filename: "images/[name].webp",
          },
        ],
      }),
    ],
  },
};

How the Configuration Works

  1. Asset Modules Rule: The test: /\.(jpe?g|png)$/i rule captures standard image files referenced in your code and emits them to the dist/images/ directory.
  2. Generators: Inside the optimization.minimizer array, the ImageMinimizerPlugin executes sharpGenerate. For every imported PNG or JPEG, it emits a corresponding .avif and .webp file matching the pattern defined in the filename option.
  3. Encoding Options: You can independently fine-tune the compression quality settings for both formats to achieve the best balance between file size and visual fidelity.

Using Generated Formats in HTML

Because Webpack generates the new files alongside the original formats, you should use the standard HTML <picture> tag. This allows the browser to negotiate the best supported format automatically, falling back to PNG or JPEG if necessary.

<picture>
  <source srcset="images/hero.avif" type="image/avif" />
  <source srcset="images/hero.webp" type="image/webp" />
  <img src="images/hero.jpg" alt="Hero Banner" width="800" height="600" />
</picture>

When importing images directly into JavaScript, reference the converted assets using the query string corresponding to the preset:

import heroPng from "./images/hero.png";
import heroWebp from "./images/hero.png?as=webp";
import heroAvif from "./images/hero.png?as=avif";

This workflow ensures full automation: keep high-resolution PNGs and JPEGs in your source code, and let Webpack handle modern format conversion and distribution automatically.
