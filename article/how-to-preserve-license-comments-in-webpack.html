How to Preserve License Comments in Webpack

This article explains how to configure Webpack to automatically extract third-party license comments from your source code and dependencies into dedicated .LICENSE.txt files. By leveraging the built-in Terser plugin, you can satisfy open-source legal requirements by preserving copyright notices without bloating your primary production JavaScript bundles.

The Role of TerserWebpackPlugin

Webpack 5 uses terser-webpack-plugin by default in production mode to minify JavaScript. Terser can be configured via the optimization.minimizer array to identify license comments—typically denoted by annotations like @license, @preserve, or leading exclamation marks (/*!)—and extract them into a separate text file associated with each output bundle.

Webpack Configuration

To explicitly define how licenses are extracted and preserved, configure the TerserPlugin inside your webpack.config.js file:

const TerserPlugin = require('terser-webpack-plugin');

module.exports = {
  mode: 'production',
  entry: './src/index.js',
  output: {
    filename: '[name].bundle.js',
    clean: true,
  },
  optimization: {
    minimize: true,
    minimizer: [
      new TerserPlugin({
        terserOptions: {
          format: {
            // Remove comments from the final bundle file
            comments: false,
          },
        },
        extractComments: {
          // Condition matching comments to preserve
          condition: /^\**!|@preserve|@license|@cc_on/i,
          // Filename pattern for the generated license file
          filename: (fileData) => {
            return `${fileData.filename}.LICENSE.txt`;
          },
          // Custom banner added to the main bundle pointing to the license file
          banner: (licenseFile) => {
            return `License information can be found in ${licenseFile}`;
          },
        },
      }),
    ],
  },
};

Configuration Options Explained

  • condition: Determines which comments are captured. Using a regular expression such as /^\**!|@preserve|@license|@cc_on/i targets standard legal notices while ignoring regular developer notes. You can also pass a custom function (astNode, comment) => boolean for fine-grained filtering.
  • filename: Specifies the name and location of the extracted file. The default is [file].LICENSE.txt[query], but providing a function allows dynamic control over the output naming convention.
  • banner: Controls the pointer comment injected at the top of the minified bundle. Setting this to true injects a default message referencing the extracted file, providing a string specifies a custom message, and setting it to false disables the banner entirely.
  • comments: false: Setting this property inside terserOptions.format guarantees that any comment extracted to the external file is completely removed from the main executable bundle, keeping file sizes as small as possible.
