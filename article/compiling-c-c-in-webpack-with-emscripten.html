Compiling C/C++ in Webpack with Emscripten

This article explains how to compile C and C++ source code into WebAssembly directly within a Webpack build pipeline using Emscripten loaders. You will learn about the required environment prerequisites, how to configure Webpack with loaders such as cpp-wasm-loader, how to structure your C/C++ source code, and how to asynchronously import and execute compiled WebAssembly functions within modern JavaScript applications.

Prerequisites

Before integrating C/C++ compilation into Webpack, ensure the following tools are installed:

  1. Node.js and npm: Required for running Webpack and managing project dependencies.
  2. Emscripten SDK (emsdk): The compiler toolchain that transforms C/C++ into WebAssembly (.wasm) and companion JavaScript glue code.

To install and activate the Emscripten SDK:

git clone https://github.com/emscripten-core/emsdk.git
cd emsdk
./emsdk install latest
./emsdk activate latest
source ./emsdk_env.sh

The emcc and em++ compilers must be available in your system PATH for Webpack loaders to access them during builds.

Project Setup and Dependencies

Initialize a Node project and install Webpack, Webpack CLI, and an Emscripten-compatible loader such as cpp-wasm-loader:

mkdir wasm-webpack-demo
cd wasm-webpack-demo
npm init -y
npm install --save-dev webpack webpack-cli cpp-wasm-loader

cpp-wasm-loader acts as a bridge between Webpack and the local Emscripten compiler (emcc/em++), executing the compilation on imported .c or .cpp files and outputting the compiled WebAssembly binary and JavaScript bindings.

Configuring Webpack

Create a webpack.config.js file in the root directory. Configure a rule to catch .c and .cpp extensions and pass them through cpp-wasm-loader:

const path = require('path');

module.exports = {
  entry: './src/index.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.js',
    publicPath: 'dist/',
  },
  module: {
    rules: [
      {
        test: /\.(c|cpp)$/,
        use: {
          loader: 'cpp-wasm-loader',
          options: {
            // Flags forwarded directly to emcc/em++
            emccFlags: [
              '-O3',
              '-s', 'EXPORTED_RUNTIME_METHODS=["ccall", "cwrap"]',
            ],
          },
        },
      },
    ],
  },
  experiments: {
    asyncWebAssembly: true,
  },
  mode: 'development',
};

Writing the C/C++ Source

Create a C file inside your source directory, for example, src/math.c. Wrap functions intended for JavaScript export with extern "C" (if using C++) and include emscripten.h with the EMSCRIPTEN_KEEPALIVE macro to prevent compiler dead-code elimination.

#include <emscripten.h>

EMSCRIPTEN_KEEPALIVE
int add(int a, int b) {
    return a + b;
}

EMSCRIPTEN_KEEPALIVE
int multiply(int a, int b) {
    return a * b;
}

Importing C/C++ in JavaScript

In src/index.js, import the C/C++ file like any other module. The loader returns an initialization function that resolves to an Emscripten Module instance once the WebAssembly binary is fetched and compiled:

import loadMathModule from './math.c';

loadMathModule().then((module) => {
  // Access exported functions using ccall
  const sum = module.ccall('add', 'number', ['number', 'number'], [15, 27]);
  console.log(`Result of add(15, 27): ${sum}`);

  // Alternatively, create a direct JavaScript wrapper using cwrap
  const multiply = module.cwrap('multiply', 'number', ['number', 'number']);
  console.log(`Result of multiply(6, 7): ${multiply(6, 7)}`);
});

Building and Running

Ensure your terminal environment has emsdk_env activated, then trigger the Webpack build:

npx webpack

During the build process:

  1. Webpack resolves the import loadMathModule from './math.c' statement.
  2. cpp-wasm-loader invokes the local emcc binary with specified optimization and export flags.
  3. Emscripten produces the .wasm binary and runtime glue code.
  4. Webpack emits the final static bundles into the dist/ directory, ready to be served by any web server.
