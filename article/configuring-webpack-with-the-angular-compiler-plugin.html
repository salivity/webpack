Configuring Webpack with the Angular Compiler Plugin

This article provides a step-by-step guide to configuring Webpack to build and bundle an Angular application using the official Angular Compiler Plugin (@ngtools/webpack). You will learn how to set up Ahead-of-Time (AoT) compilation, manage TypeScript configuration, handle component templates and styles, and produce an optimized production-ready bundle without relying entirely on the Angular CLI.

Prerequisites and Dependencies

To bundle an Angular application with Webpack, you must install the Webpack core packages, TypeScript, and the Angular build tools. Run the following command in your project directory:

npm install --save-dev webpack webpack-cli webpack-dev-server @ngtools/webpack typescript html-webpack-plugin

Ensure your project also has the core Angular packages installed, such as @angular/core, @angular/common, @angular/compiler, and @angular/compiler-cli.

1. Configure TypeScript

The Angular Compiler requires a dedicated TypeScript configuration file that targets modern JavaScript while maintaining compatibility with Angular decorators.

Create a tsconfig.app.json file:

{
  "compilerOptions": {
    "baseUrl": "./",
    "outDir": "./dist/out-tsc",
    "sourceMap": true,
    "declaration": false,
    "downlevelIteration": true,
    "experimentalDecorators": true,
    "moduleResolution": "node",
    "importHelpers": true,
    "target": "ES2022",
    "module": "ES2022",
    "lib": ["ES2022", "dom"]
  },
  "files": [
    "src/main.ts"
  ],
  "include": [
    "src/**/*.d.ts"
  ],
  "angularCompilerOptions": {
    "enableI18nLegacyMessageIdFormat": false,
    "strictInjectionParameters": true,
    "strictInputAccessModifiers": true,
    "strictTemplates": true
  }
}

2. Configure Webpack

The core integration happens inside webpack.config.js. You must use @ngtools/webpack as both a loader for TypeScript files and a plugin (AngularWebpackPlugin) to execute AoT compilation.

Create or update webpack.config.js:

const path = require('path');
const HtmlWebpackPlugin = require('html-webpack-plugin');
const { AngularWebpackPlugin } = require('@ngtools/webpack');

module.exports = (env, argv) => {
  const isProduction = argv.mode === 'production';

  return {
    mode: isProduction ? 'production' : 'development',
    devtool: isProduction ? false : 'eval-source-map',
    entry: {
      main: './src/main.ts',
    },
    output: {
      path: path.resolve(__dirname, 'dist'),
      filename: '[name].[contenthash].js',
      clean: true,
    },
    resolve: {
      extensions: ['.ts', '.js'],
    },
    module: {
      rules: [
        {
          test: /\.[jt]sx?$/,
          loader: '@ngtools/webpack',
        },
        {
          test: /\.html$/,
          loader: 'raw-loader',
        },
        {
          test: /\.css$/,
          use: ['to-string-loader', 'css-loader'],
        },
      ],
    },
    plugins: [
      new AngularWebpackPlugin({
        tsconfig: path.resolve(__dirname, 'tsconfig.app.json'),
        jitMode: false,
      }),
      new HtmlWebpackPlugin({
        template: './src/index.html',
        inject: 'body',
      }),
    ],
    devServer: {
      historyApiFallback: true,
      port: 4200,
      open: true,
    },
  };
};

3. Understanding the Configuration

  • @ngtools/webpack Loader: Replaces standard loaders like ts-loader. It coordinates with AngularWebpackPlugin to compile Angular templates and components into executable JavaScript during build time.
  • AngularWebpackPlugin: Manages the Angular compiler lifecycle. It processes Angular decorators, compiles component metadata, eliminates unused decorators, and enables Ahead-of-Time (AoT) compilation when jitMode is set to false.
  • Component Styles and Templates: Angular components load their CSS as inline strings via the styles or styleUrls property. Using to-string-loader in combination with css-loader ensures that imported component styles are delivered directly as raw strings to Angular metadata.

4. Running the Build

Add build and serve scripts to your package.json:

"scripts": {
  "build": "webpack --mode=production",
  "start": "webpack serve --mode=development"
}

Running npm run build will trigger Webpack to compile your TypeScript source files, compile component HTML and CSS inline, execute tree-shaking on unused Angular symbols, and emit production-ready assets into the dist folder.
