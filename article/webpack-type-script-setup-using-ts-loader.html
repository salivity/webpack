Webpack TypeScript Setup Using ts-loader

Compiling TypeScript with Webpack requires integrating ts-loader into your build pipeline alongside a valid TypeScript configuration. This guide outlines the necessary prerequisites, the tsconfig.json setup, and the specific module rules and resolve configurations needed in webpack.config.js to enable fast, seamless TypeScript transpilation.

1. Install Dependencies

To begin, install Webpack, the Webpack CLI, TypeScript, and ts-loader as development dependencies in your project:

npm install --save-dev webpack webpack-cli typescript ts-loader

2. Configure TypeScript (tsconfig.json)

ts-loader relies on a tsconfig.json file in your project root to read compilation options. You can generate a default file using npx tsc --init or create one manually with basic settings:

{
  "compilerOptions": {
    "outDir": "./dist",
    "target": "ES6",
    "module": "ESNext",
    "moduleResolution": "node",
    "strict": true,
    "allowJs": true,
    "sourceMap": true
  },
  "include": ["src/**/*"]
}

3. Configure Webpack (webpack.config.js)

Create or update your webpack.config.js file. The required configuration includes defining the entry point, resolving .ts and .tsx file extensions, and declaring the ts-loader rule inside module.rules.

const path = require('path');

module.exports = {
  mode: 'development',
  entry: './src/index.ts',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
    clean: true,
  },
  resolve: {
    // Enable Webpack to resolve TypeScript and JavaScript file extensions
    extensions: ['.tsx', '.ts', '.js'],
  },
  module: {
    rules: [
      {
        // Match all .ts and .tsx files
        test: /\.tsx?$/,
        use: 'ts-loader',
        exclude: /node_modules/,
      },
    ],
  },
  devtool: 'inline-source-map',
};

Explanation of Key Settings

  • resolve.extensions: Instructs Webpack to look for .ts, .tsx, and .js extensions automatically when resolving import statements, allowing statements like import { func } from './module' without specifying the extension.
  • module.rules.test: A regular expression (/\.tsx?$/) targeting all files ending in .ts or .tsx.
  • module.rules.use: Specifies ts-loader to compile the matched files via the TypeScript compiler.
  • module.rules.exclude: Prevents processing files in node_modules to avoid unnecessary overhead and performance degradation during builds.
