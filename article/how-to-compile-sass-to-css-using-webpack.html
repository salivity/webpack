How to Compile Sass to CSS Using Webpack

Compiling Sass or SCSS into browser-ready CSS using Webpack requires installing the Dart Sass compiler alongside a series of specialized Webpack loaders. This guide walks through the required packages, the setup of webpack.config.js to process stylesheets in the correct order, and the method for extracting the compiled CSS into standalone files for production use.

1. Install Required Dependencies

Webpack relies on a pipeline of loaders to process Sass. First, install the Sass compiler, sass-loader, css-loader, and either style-loader (for development) or mini-css-extract-plugin (for production).

Run the following command in your terminal:

npm install --save-dev sass sass-loader css-loader style-loader mini-css-extract-plugin
  • sass: The official Dart Sass compiler that converts Sass/SCSS to pure CSS.
  • sass-loader: Webpack loader that passes .scss or .sass files to the Dart Sass compiler.
  • css-loader: Resolves @import and url() paths inside your CSS files.
  • style-loader: Injects CSS directly into the DOM via <style> tags during development.
  • mini-css-extract-plugin: Extracts CSS into separate files for production performance.

2. Configure webpack.config.js

Loaders in Webpack are executed in reverse order (bottom-to-top or right-to-left). To properly compile Sass, the order must be: sass-loader first, then css-loader, and finally the style injector or extractor.

Here is a standard webpack.config.js configuration supporting both development and production workflows:

const path = require('path');
const MiniCssExtractPlugin = require('mini-css-extract-plugin');

module.exports = (env, argv) => {
  const isProduction = argv.mode === 'production';

  return {
    entry: './src/index.js',
    output: {
      path: path.resolve(__dirname, 'dist'),
      filename: 'bundle.js',
      clean: true,
    },
    module: {
      rules: [
        {
          test: /\.s[ac]ss$/i,
          use: [
            // Use MiniCssExtractPlugin in production, style-loader in development
            isProduction ? MiniCssExtractPlugin.loader : 'style-loader',
            // Translates CSS into CommonJS
            'css-loader',
            // Compiles Sass to CSS
            'sass-loader',
          ],
        },
      ],
    },
    plugins: [].concat(
      isProduction
        ? [
            new MiniCssExtractPlugin({
              filename: '[name].[contenthash].css',
            }),
          ]
        : []
    ),
  };
};

3. Import SCSS in Your JavaScript Entry File

Webpack builds its dependency graph starting from your entry file. Import your main Sass or SCSS file inside your primary JavaScript entry point (such as src/index.js):

import './styles/main.scss';

console.log('App initialized');

4. Compile the Assets

Add build scripts to your package.json to execute Webpack:

"scripts": {
  "build": "webpack --mode production",
  "start": "webpack serve --mode development"
}

Running npm run build will process your SCSS files, compile them into standard CSS, and output the resulting stylesheet into the dist/ directory, ready to be linked in an HTML document.
