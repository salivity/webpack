How to Enable HTTPS in Webpack Dev Server

Enabling HTTPS for local development in Webpack Dev Server allows you to test secure cookies, HTTP/2, service workers, and APIs that require a secure context. This guide covers how to quickly enable the default self-signed certificate using built-in settings, as well as how to configure custom, trusted SSL certificates for a warning-free local development experience.

Method 1: Using the Default Self-Signed Certificate

The quickest way to enable HTTPS is to use Webpack Dev Server's built-in self-signed certificate.

Open your webpack.config.js file and update the devServer configuration object:

module.exports = {
  // ... other configuration settings
  devServer: {
    server: 'https',
    port: 8080,
  },
};

(Note: For older versions of webpack-dev-server (v3 and below), use https: true instead of server: 'https'.)

Alternatively, you can start the server via the command-line interface without modifying the configuration file:

npx webpack serve --server-type https

When you navigate to https://localhost:8080, your browser will display a security warning because the default certificate is not issued by a trusted Certificate Authority (CA). You can safely bypass this warning for local testing.

Method 2: Using Custom Trusted Certificates (with mkcert)

To avoid browser security warnings, you can generate locally-trusted certificates using a tool like mkcert.

Step 1: Generate the Certificates

Install mkcert and generate a certificate for localhost:

# Install local CA
mkcert -install

# Create certificate files
mkcert localhost

This generates two files in your project directory: localhost.pem (certificate) and localhost-key.pem (private key).

Step 2: Configure Webpack Dev Server

Update your webpack.config.js to read and use these files:

const fs = require('fs');
const path = require('path');

module.exports = {
  // ... other configuration settings
  devServer: {
    server: {
      type: 'https',
      options: {
        key: fs.readFileSync(path.resolve(__dirname, 'localhost-key.pem')),
        cert: fs.readFileSync(path.resolve(__dirname, 'localhost.pem')),
      },
    },
    port: 8080,
  },
};

Restart your Webpack Dev Server. When you visit https://localhost:8080, the connection will be secure, and the browser will accept the certificate without showing a security warning. Ensure that your generated certificate files (especially the private key) are added to your .gitignore file to prevent committing them to version control.
