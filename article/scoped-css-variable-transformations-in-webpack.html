Scoped CSS Variable Transformations in Webpack

This guide provides a straightforward walkthrough on configuring Webpack to compile and extract CSS files with locally scoped CSS variable transformations. By combining mini-css-extract-plugin, css-loader, and postcss-loader with scoping plugins, you can transform CSS custom properties to prevent naming collisions across components and output clean, dedicated .css files for production.

Prerequisites and Dependencies

To scope CSS variables and extract them to standalone files, install the required loaders and plugins:

npm install --save-dev webpack webpack-cli mini-css-extract-plugin css-loader postcss-loader postcss postcss-custom-properties
  • mini-css-extract-plugin: Extracts CSS into separate files per JS file.
  • css-loader: Resolves @import and url() paths and handles CSS Modules.
  • postcss-loader: Applies PostCSS transformations.
  • postcss-custom-properties: Processes and transforms CSS custom properties (variables), allowing fallback generation or specific scope handling.

Step 1: Configure Webpack

Create or update your webpack.config.js. The configuration uses MiniCssExtractPlugin.loader to extract CSS instead of inlining it with style-loader. CSS Modules are enabled within css-loader to scope class names and identifiers, while postcss-loader handles AST-level variable transformations.

const path = require('path');
const MiniCssExtractPlugin = require('mini-css-extract-plugin');

module.exports = {
  mode: 'production',
  entry: './src/index.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.js',
    clean: true,
  },
  module: {
    rules: [
      {
        test: /\.css$/i,
        use: [
          MiniCssExtractPlugin.loader,
          {
            loader: 'css-loader',
            options: {
              modules: {
                // Generates locally scoped names for classes and identifiers
                localIdentName: '[name]__[local]--[hash:base64:5]',
                exportLocalsConvention: 'camelCase',
              },
              importLoaders: 1,
            },
          },
          {
            loader: 'postcss-loader',
            options: {
              postcssOptions: {
                config: path.resolve(__dirname, 'postcss.config.js'),
              },
            },
          },
        ],
      },
    ],
  },
  plugins: [
    new MiniCssExtractPlugin({
      filename: '[name].[contenthash].css',
    }),
  ],
};

Step 2: Configure PostCSS for Variable Transformations

Create a postcss.config.js file in the root directory. To transform custom properties based on defined scopes or append static fallbacks, configure postcss-custom-properties:

module.exports = {
  plugins: [
    [
      'postcss-custom-properties',
      {
        // Preserves the original CSS custom properties alongside static transformed values
        preserve: true,
        // Provide global fallback values for scoped variables if undefined locally
        importFrom: {
          customProperties: {
            '--primary-color': '#0070f3',
            '--base-padding': '16px',
          },
        },
      },
    ],
  ],
};

If you require custom variable rewriting (such as prefixing --my-var to --[hash]-my-var for strict CSS custom property isolation), you can pass a custom PostCSS visitor plugin inside postcss.config.js:

const scopedVariablesPlugin = () => {
  return {
    postcssPlugin: 'postcss-scope-variables',
    Declaration(decl) {
      if (decl.prop.startsWith('--')) {
        // Transform the variable declaration name
        decl.prop = `--scoped-${decl.prop.slice(2)}`;
      }
      if (decl.value.includes('var(--')) {
        // Transform variable usage
        decl.value = decl.value.replace(/var\(--([a-zA-Z0-9-_]+)\)/g, 'var(--scoped-$1)');
      }
    },
  };
};
scopedVariablesPlugin.postcss = true;

module.exports = {
  plugins: [
    scopedVariablesPlugin,
  ],
};

Step 3: Usage in Source Files

Define your component styles using CSS custom properties:

/* src/Button.module.css */
:root {
  --button-bg: #111;
  --button-color: #fff;
}

.button {
  --local-accent: #e00;
  background-color: var(--button-bg);
  color: var(--button-color);
  border: 1px solid var(--local-accent);
}

Import the CSS into your JavaScript component:

// src/index.js
import styles from './Button.module.css';

const btn = document.createElement('button');
btn.className = styles.button;
btn.innerText = 'Click Me';
document.body.appendChild(btn);

Step 4: Run the Build

Execute your Webpack build:

npx webpack

Output Result

Webpack will compile the JavaScript into dist/bundle.js and generate an extracted CSS file (e.g., dist/main.[contenthash].css).

The output CSS contains transformed, isolated class names generated by css-loader alongside transformed and scoped CSS custom properties generated by PostCSS, completely separated from the JavaScript bundle.
