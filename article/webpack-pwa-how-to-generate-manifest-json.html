Webpack PWA: How to Generate manifest.json

This guide demonstrates how to configure Webpack to generate an application manifest.json file for Progressive Web Apps (PWAs). By leveraging Webpack plugins, you can automatically generate the manifest, resize application icons, inject the necessary HTML link tags, and ensure your web application meets PWA installation standards across modern browsers.

Step 1: Install Required Dependencies

The most robust tool for generating a web app manifest in Webpack is webpack-pwa-manifest. It generates the manifest.json, resizes icons automatically for different device resolutions, and integrates with html-webpack-plugin to add the manifest link to your HTML <head>.

Run the following command in your terminal:

npm install webpack-pwa-manifest html-webpack-plugin --save-dev

Step 2: Configure Webpack

Open your webpack.config.js file. Import webpack-pwa-manifest and html-webpack-plugin, then define your PWA configuration in the plugins array.

const path = require('path');
const HtmlWebpackPlugin = require('html-webpack-plugin');
const WebpackPwaManifest = require('webpack-pwa-manifest');

module.exports = {
  mode: 'production',
  entry: './src/index.js',
  output: {
    filename: '[name].[contenthash].js',
    path: path.resolve(__dirname, 'dist'),
    clean: true,
    publicPath: '/',
  },
  plugins: [
    new HtmlWebpackPlugin({
      template: './src/index.html',
      title: 'My Progressive Web App',
    }),
    new WebpackPwaManifest({
      name: 'My Progressive Web Application',
      short_name: 'MyPWA',
      description: 'A fully functional Progressive Web App built with Webpack.',
      background_color: '#ffffff',
      theme_color: '#317EFB',
      start_url: '/',
      display: 'standalone',
      orientation: 'portrait',
      crossorigin: 'use-credentials', // Can be null, use-credentials, or anonymous
      inject: true,
      fingerprints: true,
      icons: [
        {
          src: path.resolve('src/assets/icon.png'),
          sizes: [96, 128, 192, 256, 384, 512], // Multiple sizes generated from one source
          destination: path.join('assets', 'icons'),
          purpose: 'any maskable',
        },
      ],
    }),
  ],
};

Step 3: Understanding Key Configuration Properties

  • inject: When set to true, the plugin automatically injects <link rel="manifest" href="..."> and device-specific Apple touch icon tags into the HTML generated by HtmlWebpackPlugin.
  • fingerprints: Appends a unique hash to the generated manifest filename (e.g., manifest.82736481723.json) to prevent stale browser caching.
  • icons: Points to a high-resolution source icon (ideally 512x512 pixels or larger). Webpack automatically generates all specified sizes during the build process.
  • purpose: Setting this to 'any maskable' ensures your icon adapts properly on Android devices that support adaptive icons.

Step 4: Alternative Method Using Static Assets

If you prefer to maintain a static manifest.json file manually instead of generating it, use copy-webpack-plugin to transfer it directly to your build folder.

  1. Install the plugin:
npm install copy-webpack-plugin --save-dev
  1. Add it to webpack.config.js:
const CopyWebpackPlugin = require('copy-webpack-plugin');

module.exports = {
  plugins: [
    new CopyWebpackPlugin({
      patterns: [
        { from: 'src/manifest.json', to: 'manifest.json' },
        { from: 'src/icons', to: 'icons' },
      ],
    }),
  ],
};
  1. Manually reference the manifest in your source index.html:
<link rel="manifest" href="/manifest.json" />

Step 5: Verify the Manifest

  1. Run your build script:
npm run build
  1. Inspect the output directory (dist) to verify the presence of manifest.json and generated icon files.
  2. Serve your application locally and open Chrome DevTools.
  3. Navigate to the Application panel and select Manifest in the left sidebar to confirm that the browser reads your manifest details, theme colors, and icons correctly.
