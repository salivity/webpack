How to Handle PDFs as Asset URLs in Webpack

Modern web applications frequently require linking to static binary files, such as PDFs, spreadsheets, or documents, for direct client-side download. This article explains how to configure Webpack 5 to process PDF and binary files using native Asset Modules, emit them to your distribution directory, and import their resolved URLs directly into your application code for seamless file downloading.

Webpack 5 Native Asset Modules

In Webpack 5, the legacy file-loader and url-loader packages have been deprecated in favor of built-in Asset Modules. To handle PDFs or arbitrary binary files and generate a direct public URL, you use the asset/resource module type. This instructs Webpack to emit a separate file into the output directory and export the relative or absolute public URL.

Webpack Configuration

Update your webpack.config.js file by adding a rule to the module.rules array targeting PDF and other binary document extensions:

const path = require('path');

module.exports = {
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
    publicPath: '/', // Ensure publicPath matches your deployment setup
    clean: true,
  },
  module: {
    rules: [
      {
        test: /\.(pdf|docx?|xlsx?|pptx?)$/i,
        type: 'asset/resource',
        generator: {
          filename: 'documents/[name].[contenthash][ext]',
        },
      },
    ],
  },
};

Configuration Details

  • test: A regular expression matching the file types you want to treat as binary assets.
  • type: 'asset/resource': Emits the file to the build directory and returns its URL string upon import.
  • generator.filename: Specifies the output location and naming pattern. Using [name].[contenthash][ext] ensures files are placed inside a documents/ folder with unique content hashes for long-term browser caching.

Using the Asset in Your Application

Once the loader is configured, you can import the file directly into your JavaScript or TypeScript source files. The imported value resolves to a string representing the output URL.

import documentPdf from './assets/terms-and-conditions.pdf';

const link = document.createElement('a');
link.href = documentPdf;
link.download = 'Terms-and-Conditions.pdf'; // Forces download instead of opening in-browser
link.textContent = 'Download Terms and Conditions';

document.body.appendChild(link);

TypeScript Type Declaration

If you are using TypeScript, you must declare the module extension so the compiler recognizes non-code imports. Add the following definition to a declaration file (for example, src/declarations.d.ts):

declare module '*.pdf' {
  const content: string;
  export default content;
}
