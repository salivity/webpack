Webpack Expose Global Variable to Window

This article explains how to configure Webpack to expose your bundled code as a global variable attached to the browser's window object. By leveraging Webpack's library output options, you can make functions, classes, or entire modules accessible to external scripts and legacy code running in the global scope.

To expose a bundle as a global variable on the window object, you configure the output.library property in your webpack.config.js file.

Modern Webpack (Webpack 5) Configuration

In Webpack 5, the standard approach uses output.library.name to define the variable name and output.library.type set to 'window':

const path = require('path');

module.exports = {
  entry: './src/index.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.js',
    library: {
      name: 'MyGlobalLib',
      type: 'window',
    },
  },
};

Legacy Configuration (Webpack 4 and Earlier)

In older versions of Webpack, the same behavior is achieved using output.library and output.libraryTarget:

const path = require('path');

module.exports = {
  entry: './src/index.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.js',
    library: 'MyGlobalLib',
    libraryTarget: 'window',
  },
};

How to Export from Your Entry File

Webpack attaches whatever your entry file (./src/index.js) exports to the specified global variable.

If you use ES Modules:

// src/index.js
export function greet(name) {
  return `Hello, ${name}!`;
}

export const version = '1.0.0';

In the browser, after loading bundle.js with a standard <script> tag, your exports are accessible globally:

<script src="dist/bundle.js"></script>
<script>
  window.MyGlobalLib.greet('World'); // Returns "Hello, World!"
  console.log(window.MyGlobalLib.version); // Prints "1.0.0"
</script>

If your entry point uses a default export (export default), the object will be available under window.MyGlobalLib.default. To assign the default export directly to the global variable, set output.library.export: 'default' in your Webpack configuration.
