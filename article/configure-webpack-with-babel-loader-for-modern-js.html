Configure Webpack with Babel-Loader for Modern JS

This guide provides a straightforward walkthrough on configuring Webpack to transpile modern JavaScript (ES6+) into backward-compatible code using babel-loader. By integrating Webpack with Babel's core compiler and standard presets, you can write modern ECMAScript features while ensuring broad browser compatibility.

1. Install Required Dependencies

First, install Webpack, the Webpack CLI, Babel core, babel-loader, and the environment preset as development dependencies:

npm install --save-dev webpack webpack-cli babel-loader @babel/core @babel/preset-env
  • webpack & webpack-cli: The core bundler and command-line interface.
  • @babel/core: The central Babel compiler engine.
  • babel-loader: The Webpack loader allowing Babel to process JavaScript files.
  • @babel/preset-env: A smart preset that determines the necessary Babel plugins and polyfills based on target environments.

2. Configure Babel

Create a Babel configuration file named babel.config.json in the root of your project:

{
  "presets": [
    [
      "@babel/preset-env",
      {
        "targets": "> 0.25%, not dead"
      }
    ]
  ]
}

The targets field informs Babel which browser environments your output bundle must support, ensuring only the necessary transformations are applied.

3. Configure Webpack

Create or open your webpack.config.js file in the root directory and define a module rule for JavaScript files:

const path = require('path');

module.exports = {
  mode: 'development',
  entry: './src/index.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.js',
    clean: true,
  },
  module: {
    rules: [
      {
        test: /\.(?:js|mjs|cjs)$/,
        exclude: /node_modules/,
        use: {
          loader: 'babel-loader',
        },
      },
    ],
  },
};

Key parts of this configuration include:

  • test: A regular expression matching .js, .mjs, and .cjs files.
  • exclude: Ignores node_modules to prevent transpiling external libraries, significantly speeding up build times.
  • use: Specifies babel-loader as the handler for matching files, which automatically reads the babel.config.json file.

4. Run the Build

Add a build script to your package.json:

"scripts": {
  "build": "webpack"
}

Execute the command:

npm run build

Webpack will process your entry file, route any matching JavaScript through babel-loader using @babel/preset-env, and emit the transpiled code into the dist/ directory.
