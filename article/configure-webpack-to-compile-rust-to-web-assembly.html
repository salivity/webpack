Configure Webpack to Compile Rust to WebAssembly

Compiling Rust directly to WebAssembly (Wasm) inside a Webpack build allows developers to leverage near-native execution speed for CPU-heavy tasks without abandoning existing front-end workflows. This guide demonstrates how to configure Webpack 5 to handle an on-the-fly Rust asset pipeline using @wasm-tool/wasm-pack-plugin, detailing the required project structure, Rust configuration, Webpack settings, and JavaScript consumption.

Prerequisites

Ensure the following tools are installed on your machine:

  • Rust Toolchain: Install via rustup from the official Rust website.
  • wasm-pack: Install globally by running cargo install wasm-pack or using the pre-built installer.
  • Node.js & npm: A modern LTS version.

1. Initialize the Project Structure

Create a unified directory containing both your Node.js application and the Rust crate:

rust-wasm-webpack/
├── Cargo.toml
├── src/
│   └── lib.rs
├── package.json
├── webpack.config.js
└── js/
    └── index.js

2. Configure the Rust Crate

In your Cargo.toml, define the crate type as a C dynamic library (cdylib) and add wasm-bindgen as a dependency. This enables Rust to generate bindings suitable for the web.

[package]
name = "rust-wasm-module"
version = "0.1.0"
edition = "2021"

[lib]
crate-type = ["cdylib"]

[dependencies]
wasm-bindgen = "0.2"

In src/lib.rs, export a basic function to test the pipeline:

use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub fn add(a: i32, b: i32) -> i32 {
    a + b
}

3. Install Webpack Dependencies

Install Webpack, its CLI, dev server, and the wasm-pack Webpack plugin:

npm init -y
npm install --save-dev webpack webpack-cli webpack-dev-server @wasm-tool/wasm-pack-plugin html-webpack-plugin

4. Configure Webpack

In webpack.config.js, enable Webpack 5's asynchronous WebAssembly experiment and instantiate @wasm-tool/wasm-pack-plugin. The plugin invokes wasm-pack during the build step whenever Rust files change.

const path = require("path");
const HtmlWebpackPlugin = require("html-webpack-plugin");
const WasmPackPlugin = require("@wasm-tool/wasm-pack-plugin");

module.exports = {
  entry: "./js/index.js",
  output: {
    path: path.resolve(__dirname, "dist"),
    filename: "bundle.js",
  },
  experiments: {
    asyncWebAssembly: true,
  },
  plugins: [
    new HtmlWebpackPlugin({
      title: "Rust WebAssembly Webpack Demo",
    }),
    new WasmPackPlugin({
      crateDirectory: path.resolve(__dirname, "."),
      outDir: path.resolve(__dirname, "pkg"),
    }),
  ],
  mode: "development",
};

5. Import and Run the WebAssembly Module

Because WebAssembly compiles asynchronously in Webpack 5, load the generated package dynamically using import().

In js/index.js:

import("../pkg")
  .then((wasm) => {
    const result = wasm.add(15, 27);
    console.log(`Result from Rust: ${result}`);
    document.body.innerText = `Result from Rust: ${result}`;
  })
  .catch((err) => {
    console.error("Error loading Wasm module:", err);
  });

6. Build and Test

Add a start script to your package.json:

"scripts": {
  "start": "webpack serve --open",
  "build": "webpack"
}

Running npm start executes wasm-pack build, writes the output to the /pkg directory, runs the dev server, and hot-reloads the application whenever you modify your .rs source code.
