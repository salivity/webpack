Inline SVG as React Components with SVGR and Webpack

Inlining SVGs directly as React components allows developers to manipulate vector graphics with props, CSS classes, and dynamic styling without the overhead of external HTTP requests. This guide demonstrates how to install and configure @svgr/webpack within your Webpack build pipeline to automatically transform imported SVG files into fully interactive React components, resolve common loader conflicts, and properly set up TypeScript support.

1. Install @svgr/webpack

Install the loader as a development dependency using npm or Yarn:

npm install --save-dev @svgr/webpack
# or
yarn add --dev @svgr/webpack

2. Configure webpack.config.js

Add a new rule to the module.rules array in your Webpack configuration. Using the issuer property ensures that @svgr/webpack only processes SVGs imported inside JavaScript, TypeScript, or JSX/TSX files.

module.exports = {
  module: {
    rules: [
      {
        test: /\.svg$/i,
        issuer: /\.[jt]sx?$/,
        use: ['@svgr/webpack'],
      },
    ],
  },
};

If you are using Webpack 5 and want to support both inlined React components and standard static image URLs, configure resource queries:

module.exports = {
  module: {
    rules: [
      {
        test: /\.svg$/i,
        issuer: /\.[jt]sx?$/,
        resourceQuery: { not: [/url/] }, // exclude imports with *.svg?url
        use: ['@svgr/webpack'],
      },
      {
        test: /\.svg$/i,
        type: 'asset/resource',
        resourceQuery: /url/, // import iconUrl from './icon.svg?url'
      },
    ],
  },
};

3. Import and Render SVGs in React

Once configured, Webpack transforms the SVG file into a standard React component during compilation. You can import the SVG and pass standard SVG attributes or custom classes as props:

import React from 'react';
import Icon from './assets/icon.svg';

const Button = () => {
  return (
    <button type="button">
      <Icon width={24} height={24} fill="currentColor" className="icon-class" />
      <span>Click Me</span>
    </button>
  );
};

export default Button;

4. Configure TypeScript Declarations (Optional)

If your project uses TypeScript, declare the module shape so the compiler recognizes default SVG imports as React components. Create or update a custom.d.ts file in your source directory:

declare module '*.svg' {
  import React from 'react';
  const SVG: React.FC<React.SVGProps<SVGSVGElement>>;
  export default SVG;
}

Ensure the declaration file is included in your tsconfig.json under the include array.
