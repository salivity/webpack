Webpack Dev Server Open Browser on Launch

Configuring Webpack Dev Server to open your default web browser automatically upon startup streamlines local development workflows. This article details the specific configuration property required in your Webpack configuration file, demonstrates command-line alternatives, and outlines options for opening specific browser applications or URLs.

The open Configuration Property

To instruct Webpack Dev Server to open the default system browser on launch, set the open property to true inside the devServer configuration object in your webpack.config.js file:

const path = require('path');

module.exports = {
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
  devServer: {
    static: './dist',
    port: 8080,
    open: true, // Instructs the dev server to open the default browser
  },
};

When you execute webpack serve, the server will build your project, bind to the defined port (such as http://localhost:8080), and immediately trigger your operating system's default browser to open that URL.

Command Line Interface (CLI) Alternative

If you do not want to hardcode this behavior into your configuration file, you can pass the --open flag directly via the command line:

npx webpack serve --open

You can also assign this command to a script inside your package.json:

"scripts": {
  "start": "webpack serve --open"
}

Advanced open Configurations

Webpack Dev Server also accepts arrays or objects for the open property to customize what opens and how:

  • Open a Specific Page: To open a path other than the root URL, specify the path as a string or array:

    devServer: {
  open: ['/dashboard.html'],
}

  • Specify a Browser Application: To launch a specific browser rather than the system default, define the app property:

    devServer: {
  open: {
    app: {
      name: 'google-chrome', // or 'chrome', 'firefox', etc., depending on OS
    },
  },
}
