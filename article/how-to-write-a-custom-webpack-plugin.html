How to Write a Custom Webpack Plugin

Writing a custom Webpack plugin allows developers to deeply integrate into the build lifecycle to automate tasks, generate assets, or manipulate emitted bundles. This guide explains how to construct a Webpack plugin from scratch by implementing the plugin class and leveraging compiler and compilation hooks using Webpack's Tapable event system.

The Anatomy of a Webpack Plugin

A Webpack plugin is a JavaScript class (or function) with an apply method. The Webpack compiler calls this apply method once when initializing the plugin, passing an instance of the compiler object.

class MyCustomPlugin {
  constructor(options = {}) {
    this.options = options;
  }

  apply(compiler) {
    // Hooks are tapped here
  }
}

module.exports = MyCustomPlugin;

Compiler vs. Compilation

Understanding the lifecycle requires distinguishing between the two primary objects:

  • Compiler: Represents the fully configured Webpack environment. It starts when Webpack launches and persists until it exits. Use compiler hooks to tap into high-level lifecycle events like initialization, environment setup, and final asset emissions.
  • Compilation: Created by the compiler each time a build is triggered (including file changes in watch mode). It contains the dependency graph, modules, and chunk configurations. Use compilation hooks to inspect or alter modules, chunks, and individual generated assets.

Tapping into Compiler Hooks

Webpack hooks use the Tapable library. Depending on whether a hook is synchronous or asynchronous, you tap into it using different methods:

  • .tap() for synchronous hooks.
  • .tapAsync() for callback-based asynchronous hooks.
  • .tapPromise() for Promise-based asynchronous hooks.

To access the compilation lifecycle, listen to the compiler’s thisCompilation or compilation hook:

compiler.hooks.thisCompilation.tap('MyCustomPlugin', (compilation) => {
  // Access compilation hooks here
});

Tapping into Compilation Hooks

Inside the thisCompilation callback, you can tap into specific compilation stages. In Webpack 5, the standard way to inspect or generate output files is the processAssets hook.

const { Compilation } = require('webpack');

compiler.hooks.thisCompilation.tap('MyCustomPlugin', (compilation) => {
  compilation.hooks.processAssets.tap(
    {
      name: 'MyCustomPlugin',
      stage: Compilation.PROCESS_ASSETS_STAGE_ADDITIONS,
    },
    (assets) => {
      // Modify or add to compilation assets
    }
  );
});

Complete Example: An Asset-Generating Plugin

The following example demonstrates a custom plugin that generates a build-manifest.txt file listing all emitted file names and their sizes.

const { Compilation, sources } = require('webpack');

class BuildManifestPlugin {
  constructor(options = {}) {
    this.outputFilename = options.filename || 'build-manifest.txt';
  }

  apply(compiler) {
    const pluginName = BuildManifestPlugin.name;

    // 1. Hook into the compilation creation
    compiler.hooks.thisCompilation.tap(pluginName, (compilation) => {
      // 2. Hook into the asset processing phase
      compilation.hooks.processAssets.tap(
        {
          name: pluginName,
          stage: Compilation.PROCESS_ASSETS_STAGE_SUMMARIZE,
        },
        (assets) => {
          let manifestContent = 'Generated Assets:\n';

          for (const [filename, asset] of Object.entries(assets)) {
            manifestContent += `${filename} - ${asset.size()} bytes\n`;
          }

          // 3. Emit the new file using Webpack sources
          compilation.emitAsset(
            this.outputFilename,
            new sources.RawSource(manifestContent)
          );
        }
      );
    });

    // 4. Hook into a high-level compiler hook
    compiler.hooks.done.tap(pluginName, (stats) => {
      console.log('Build completed successfully.');
    });
  }
}

module.exports = BuildManifestPlugin;

Using the Custom Plugin

To use your plugin, instantiate it in the plugins array inside your webpack.config.js file:

const path = require('path');
const BuildManifestPlugin = require('./plugins/BuildManifestPlugin');

module.exports = {
  entry: './src/index.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.js',
  },
  plugins: [
    new BuildManifestPlugin({
      filename: 'manifest.txt',
    }),
  ],
};
