How to Compress Webpack Assets with CompressionPlugin

This guide demonstrates how to configure Webpack to pre-compress your production build assets into Gzip and Brotli formats using compression-webpack-plugin. Pre-compressing assets during the build process reduces server CPU usage during requests, significantly decreases file transfer sizes, and improves page load performance for end users.

Step 1: Install the Plugin

Install compression-webpack-plugin as a development dependency using npm or yarn:

npm install compression-webpack-plugin --save-dev

or

yarn add compression-webpack-plugin --dev

Step 2: Configure Gzip Compression

Gzip is supported by virtually all modern browsers. To enable Gzip compression, require the plugin in your webpack.config.js and add an instance of it to the plugins array.

const CompressionPlugin = require("compression-webpack-plugin");

module.exports = {
  // ... other webpack configuration
  plugins: [
    new CompressionPlugin({
      filename: "[path][base].gz",
      algorithm: "gzip",
      test: /\.(js|css|html|svg)$/,
      threshold: 10240, // Only assets larger than 10KB
      minRatio: 0.8,    // Only compress if the compression ratio is at least 0.8
    }),
  ],
};

Step 3: Configure Brotli Compression

Brotli generally provides superior compression ratios compared to Gzip. Node.js has native Brotli support (via the zlib module) in Node 11.7.0 and later, allowing you to use algorithm: "brotliCompress".

const CompressionPlugin = require("compression-webpack-plugin");
const zlib = require("zlib");

module.exports = {
  // ... other webpack configuration
  plugins: [
    new CompressionPlugin({
      filename: "[path][base].br",
      algorithm: "brotliCompress",
      test: /\.(js|css|html|svg)$/,
      compressionOptions: {
        params: {
          [zlib.constants.BROTLI_PARAM_QUALITY]: 11, // Maximum compression
        },
      },
      threshold: 10240,
      minRatio: 0.8,
    }),
  ],
};

Step 4: Generating Both Gzip and Brotli Simultaneously

To ensure full browser compatibility while providing maximum compression for supporting clients, you can instantiate CompressionPlugin twice in your configuration.

const CompressionPlugin = require("compression-webpack-plugin");
const zlib = require("zlib");

module.exports = {
  mode: "production",
  // ... entry, output, loaders
  plugins: [
    // Gzip configuration
    new CompressionPlugin({
      filename: "[path][base].gz",
      algorithm: "gzip",
      test: /\.(js|css|html|svg)$/,
      threshold: 10240,
      minRatio: 0.8,
    }),
    // Brotli configuration
    new CompressionPlugin({
      filename: "[path][base].br",
      algorithm: "brotliCompress",
      test: /\.(js|css|html|svg)$/,
      compressionOptions: {
        params: {
          [zlib.constants.BROTLI_PARAM_QUALITY]: 11,
        },
      },
      threshold: 10240,
      minRatio: 0.8,
    }),
  ],
};

Common Configuration Options

  • test: A RegExp, string, or array defining which file types should be targeted. Typically includes JavaScript, CSS, HTML, and SVG files. Binary assets like images (JPEG, PNG) are already compressed and should be excluded.
  • threshold: Minimum file size (in bytes) required for compression to occur. Small files often become larger after compression due to metadata overhead.
  • minRatio: Discards compressed output if the ratio of the compressed size to the original size exceeds this threshold.
  • deleteOriginalAssets: Setting this to true removes the uncompressed file. Keep this set to false (the default) so your server can still serve fallback files to older clients.

Server-Side Delivery

Pre-compressed files generated with .gz and .br extensions require a web server configured to serve them based on the incoming request's Accept-Encoding header:

  • Nginx: Use the gzip_static on; directive for Gzip and the brotli_static on; directive (via ngx_brotli) for Brotli.
  • Apache: Use mod_deflate with rewrite rules pointing to the static .gz and .br files.
  • Caddy: Use the file_server directive, which automatically discovers .gz and .br sidecar files by default.
