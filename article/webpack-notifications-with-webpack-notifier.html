Webpack Notifications with webpack-notifier

Integrating desktop notifications into your Webpack build pipeline keeps you informed of build statuses, errors, and warnings without requiring you to constantly monitor the terminal. This guide covers how to install, configure, and customize the webpack-notifier plugin to display native operating system notifications during development.

1. Installation

The webpack-notifier package wraps node-notifier to send native notifications on macOS, Windows, and Linux. Install it as a development dependency using npm or yarn:

npm install --save-dev webpack-notifier

or

yarn add --dev webpack-notifier

2. Basic Configuration

To enable build notifications, require the plugin inside your webpack.config.js file and add an instance of it to the plugins array.

const path = require('path');
const WebpackNotifierPlugin = require('webpack-notifier');

module.exports = {
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
  plugins: [
    new WebpackNotifierPlugin(),
  ],
};

By default, this will display a system notification whenever a build fails, alerting you to syntax errors, unresolved dependencies, or configuration issues.

3. Customizing Plugin Options

webpack-notifier accepts an options object to modify how and when alerts appear:

  • alwaysNotify: By default (false), notifications are only triggered on errors. Setting this to true sends a notification on every build, including successful ones.
  • title: Sets the notification window title. Useful for differentiating multiple microservices or applications.
  • excludeWarnings: Set to true to suppress notifications for compilation warnings, notifying only on fatal errors.
  • contentImage: Absolute path to an image file used as the icon inside the notification.

Example configuration with options:

const path = require('path');
const WebpackNotifierPlugin = require('webpack-notifier');

module.exports = {
  plugins: [
    new WebpackNotifierPlugin({
      title: 'My Project Build',
      alwaysNotify: true,
      excludeWarnings: true,
      contentImage: path.join(__dirname, 'assets/logo.png'),
    }),
  ],
};

4. Conditional Setup for Development Only

Because system notifications are distracting and unnecessary in Continuous Integration (CI) or production build environments, instantiate the plugin conditionally based on your environment:

const WebpackNotifierPlugin = require('webpack-notifier');

module.exports = (env, argv) => {
  const isDev = argv.mode === 'development';

  return {
    mode: argv.mode,
    plugins: [
      ...(isDev ? [
        new WebpackNotifierPlugin({
          alwaysNotify: false,
          title: 'Development Build',
        }),
      ] : []),
    ],
  };
};

5. OS-Specific Requirements

  • macOS: Works natively with Notification Center without extra configuration.

  • Windows: Uses the Windows Action Center (Windows 8 and above). Ensure the "Focus Assist" setting allows notifications.

  • Linux: Requires libnotify-bin to trigger notify-send. On Ubuntu/Debian, install it via:

    sudo apt-get install libnotify-bin
