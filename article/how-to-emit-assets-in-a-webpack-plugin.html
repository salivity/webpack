How to Emit Assets in a Webpack Plugin

Emitting assets directly into the Webpack compilation pipeline allows plugins to generate virtual files, inject build manifests, or create dynamic output files without reading them from disk. In modern Webpack (v5+), this is achieved using the processAssets compilation hook combined with the compilation.emitAsset API and sources from the webpack-sources library.

Understanding the Plugin Architecture

To emit an asset, a Webpack plugin hooks into the thisCompilation event on the compiler instance. Inside this hook, the plugin accesses the active compilation object and taps into the processAssets hook, which organizes asset generation and modification across predefined build stages.

Implementation Example

The following example demonstrates a custom plugin emitting a generated JSON file during the build process:

const { Compilation, sources } = require('webpack');

class EmitNewAssetPlugin {
  constructor(options = {}) {
    this.filename = options.filename || 'generated-asset.json';
  }

  apply(compiler) {
    const pluginName = EmitNewAssetPlugin.name;

    compiler.hooks.thisCompilation.tap(pluginName, (compilation) => {
      compilation.hooks.processAssets.tap(
        {
          name: pluginName,
          // Use a stage appropriate for creating new files
          stage: Compilation.PROCESS_ASSETS_STAGE_ADDITIONAL,
        },
        () => {
          const content = JSON.stringify({
            timestamp: Date.now(),
            status: 'success',
          }, null, 2);

          // Wrap the string or buffer in a Webpack Source object
          const source = new sources.RawSource(content);

          // Emit the asset into the compilation
          compilation.emitAsset(this.filename, source);
        }
      );
    });
  }
}

module.exports = EmitNewAssetPlugin;

Key Components

  1. compiler.hooks.thisCompilation: Runs whenever Webpack creates a new compilation instance. Tapping here ensures that your plugin has direct access to the compilation object while supporting child compilers and watch mode correctly.

  2. compilation.hooks.processAssets: Webpack 5's dedicated hook for asset manipulation. It accepts an options object containing a name and a stage.

  3. Asset Stages (Compilation.PROCESS_ASSETS_STAGE_*):

    • PROCESS_ASSETS_STAGE_ADDITIONAL: Used to add assets derived from configuration, source files, or remote data.
    • PROCESS_ASSETS_STAGE_PRE_PROCESS: Used when assets must be created before basic loaders or transforms run.
    • PROCESS_ASSETS_STAGE_OPTIMIZE: Used when manipulating assets already produced by other plugins or loaders.
    • PROCESS_ASSETS_STAGE_SUMMARIZE: Used for generating metadata or summary files, such as build stats or service worker manifests.

  4. webpack-sources: Assets added via compilation.emitAsset cannot be plain strings or buffers. They must be wrapped in a class implementing the Webpack Source interface (such as RawSource, ConcatSource, or SourceMapSource) to facilitate subsequent source map generation, asset hashing, and minimization.

  5. compilation.emitAsset(name, source, assetInfo): This method registers the asset in the compilation output table. It takes the output filename relative to the output directory, the Source object, and an optional assetInfo object defining properties like minimized or immutable.
